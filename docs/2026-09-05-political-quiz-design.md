# 时政测验功能设计

日期：2026-09-05

## 目标

在研申现有侧边栏中新增一级入口“时政测验”，将 `weekly-political-theory-quiz` Skill 的命题规则、题型结构、逐条解析、设误点清单和速查能力原生化。功能既能直接练习已经核验的本期题包，也能通过本机 ChatGPT/Codex 登录实时联网检索并生成最新题包。

## 产品原则

1. **政治表述准确优先于题量**：实时生成必须显式要求官方来源，无法核验时宁可减少题目，不允许用模型记忆补齐政策原文。
2. **原生化而非嵌 HTML**：Skill 中的 CARDS / QS / TRAPS / CHEAT 转为统一题包 JSON，页面由研申自身 HTML/CSS/JS 渲染。
3. **练习和考试双模式**：练习模式逐题即时判分并展开逐条解析；考试模式作答期间隐藏答案，统一交卷后展示成绩与解析。
4. **默认少一步操作**：进入页面默认“国考 + 本月 + 20题”，省考和省份属于高级筛选，不增加启动前的必经向导。
5. **来源可追溯**：每题展示来源名称、日期、URL；题包页展示官方来源覆盖率和核验状态。

## 信息架构

### 侧边栏

顺序：主页 → 题库 → 学习记录 → 错题本 → **时政测验** → AI 教练 → 设置。

时政测验是独立一级模块，不放进“题库”二级菜单，因为其内容来源、答题模型和更新周期与申论题库不同。

### `/political-quiz`

页面上半区是一张“本期训练”主卡，右侧为紧凑参数区：

- 考试：国考（默认）/ 省考
- 省份：仅省考时出现
- 时间：本月（默认）/ 近30日 / 上月重点回炉
- 题量：10 / 20（默认）/ 30
- 模式：练习 / 考试

主操作：

- `开始本期核验题`：优先使用数据库中最新 `verified` 题包。
- `生成最新测验`：调用 ChatGPT/Codex 联网研究生成通道。

下方三块：

1. **本期重头考点**：中央文件、重要会议/讲话、马原、民生、法治等主题分布。
2. **最近测验**：日期、模式、得分、正确率、用时，点击继续复盘。
3. **易错雷达**：方向颠倒、绝对化、偷换关键词、无中生有、张冠李戴五类累计错误。

### `/political-quiz/packs/{id}`

测验页采用单列阅读版心，顶部粘性进度条。

练习模式：
- 点选后锁题。
- 即时显示对错。
- combo/count/count5 逐条给 ①②③④/⑤ 打 √/×。
- 展开每条解析和官方来源。
- 错题下方突出“圈出错项关键三字”。

考试模式：
- 题目可前后跳转，允许修改答案。
- 不显示 truth / explanation / trap。
- 顶部显示已答题数和剩余未答。
- 交卷后一次性判分并进入结果区。

### 结果区

- 总分/正确率/用时。
- 考点正确率：马原、中央文件、会议讲话、民生、法治、周年、对应关系。
- 干扰项错误结构：五手法统计。
- “本次最该记住的 3 个错项关键字”。
- 操作：只做错题 / 再做一遍 / 返回时政首页。

### 易错清单与速查

题包完成后原生展示 Skill 的第三、四段：
- 设误点与易错点清单：按考点分组，红色错误表述 → 墨绿色正确表述 → 手法标签。
- 干扰项五手法速查。
- 本期数字类考点速记。

## 数据模型

### `political_quiz_packs`

- `id`
- `pack_key`：唯一，如 `2026-09-national-20-verified`
- `title`
- `exam_scope`：`national` / `province`
- `province`
- `period_label`
- `question_count`
- `status`：`generating` / `ready` / `failed`
- `verification_status`：`generated` / `verified`
- `source_count`
- `data_json`：完整题包 JSON
- `generation_prompt`
- `generation_error`
- `created_at` / `updated_at`

### `political_quiz_attempts`

- `id`
- `pack_id`
- `mode`：`practice` / `exam`
- `answers_json`
- `correct_count`
- `question_count`
- `elapsed_seconds`
- `completed_at`
- `created_at`

## 题包 JSON

顶层字段：`meta`, `cards`, `questions`, `traps`, `cheat`。

`questions` 沿用 Skill 的语义字段并扩展为稳定 JSON：

- `type`: `combo|count|count5|pick|map|multi`
- `stem`
- `ask`
- `statements`
- `truth`
- `options`
- `answer_index`
- `explanations`
- `source`: `{name,date,url}`
- `topic`
- `trap_type`
- `key_words`

校验规则：四选一必须 4 个选项；count/count5 的正确项数量必须与答案选项一致；combo 组合必须升序；每题必须有来源；解释条数与 statements 对齐；题号必须被 traps 覆盖。

## 实时生成

实时生成仅在 ChatGPT/Codex 账号模式启用。新增专用 `codex_research_completion()`，在现有 `codex exec` 基础上显式启用联网搜索，保持只读沙箱和临时工作目录。

生成提示词由 `weekly-political-theory-quiz` 规则转成 JSON 协议，关键约束：

- 只采用新华社、人民日报、中国政府网、求是网、中央/国务院部门官网、最高法等官方来源。
- 网友回忆版只允许用于题型趋势，不得作为政治表述来源。
- 默认 20 题，国考配比：组合3、计数3（至少1道5条）、选非5、选是9；答案 ABCD 尽量均衡。
- 省考：组合4、计数4、选非4、选是8；追加省情材料，马原约2题。
- 输出必须是单个 JSON 对象。
- 后端保存前执行结构质检；未通过则不入库并返回明确错误。

API 模式不具备内建联网搜索时，不伪装成“最新”；页面提示切换到 ChatGPT/Codex 账号连接后再生成。

## 视觉规范

完全沿用现有研申设计变量：`--ink`, `--muted`, `--paper`, `--panel`, `--line`, `--green`, `--green-2`, `--gold`, `--blue`。

新增时政页不引入外部字体、框架或 CDN。重点视觉：

- 页面标题采用现有 editorial page-head 语言。
- 本期主卡是浅纸色大区块，不做高饱和渐变。
- “已核验”使用低饱和绿色印章式状态；“实时生成”使用蓝灰色网络图标提示。
- 选项默认白底细边；答对用墨绿软底；答错用暖红/褐红软底，避免刺眼纯红。
- 解析区更像批注纸：左侧细竖线 + 逐条编号，而不是通用 SaaS 卡片堆叠。
- 手机/窄窗口改成单列，顶部进度条保留。

## 错误与边界处理

- 无已核验题包：主按钮变为“生成本期测验”，明确说明当前还没有核验题包。
- Codex 未登录：生成按钮仍可点，返回设置入口与登录提示。
- 网络研究失败：保留失败记录但不产生可答题包。
- JSON 质检失败：展示具体失败原因，不保存半成品。
- 关闭页面：练习/考试答案写本地数据库，可继续作答。
- 打印：仅完成后的结果/解析允许打印；未交卷考试模式不得通过打印样式泄题。

## 测试要求

1. 数据校验单测：题型、答案、解析、来源、trap 覆盖。
2. 路由与侧边栏单测：`/political-quiz` 与题包页可访问，active 状态正确。
3. 持久化单测：题包保存、继续答题、完成成绩。
4. 前端交互测试：练习锁题、考试可改、交卷后统一揭晓、重新开始。
5. 既有完整 Python 与前端测试必须保持通过。
